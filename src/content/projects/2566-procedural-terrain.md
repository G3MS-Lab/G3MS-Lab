A GPU-accelerated procedural terrain generator that combines fractal noise heightmaps with hydraulic and thermal erosion simulation, producing realistic landscapes for game environments. The system runs fully on the GPU using compute shaders, allowing interactive parameter adjustment at 60 fps for terrains up to 4096×4096 resolution. The project was integrated into a game demo built with Unity.
