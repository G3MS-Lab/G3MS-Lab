This senior project develops a WebGL-based point cloud viewer optimized for mobile browsers, enabling field engineers to inspect 3D LiDAR scans directly on tablets without specialized software. The system supports progressive loading of large point clouds (up to 10M points) using an octree-based level-of-detail scheme and provides touch-friendly navigation controls. Testing on site inspection workflows at a construction company demonstrated a 40% reduction in data review time.
